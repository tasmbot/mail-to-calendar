# 📅 mail-to-calendar
Серверлесс-функция на Yandex Cloud, которая автоматически отслеживает дедлайны в почте и добавляет их в календарь Apple iCloud.
Функция поддерживает два режима:
- Парсинг .ics вложений (стандартные приглашения).
- Парсинг текстовых писем (например, уведомления из LMS вроде Moodle/Canvas с дедлайнами и ссылками).
## 🏗 Архитектура
Yandex Mail (IMAP) ➔ Yandex Cloud Timer (Cron) ➔ Yandex Cloud Function (Python 3.12) ➔ Apple iCloud (CalDAV)
## 📋 Предварительные требования
1. Аккаунт Yandex Cloud с правами на создание функций и триггеров.
2. Яндекс.Почта:
 - Создайте папку для писем с дедлайнами (например, iCloud или Учеба).
 - Важно: Сгенерируйте Пароль приложений (не основной пароль от аккаунта!). Путь: Яндекс ID → Безопасность → Пароли приложений → Создать для «Почты».
3. Apple ID:
- Создайте календарь в iCloud (например, Учеба).
- Важно: Сгенерируйте Пароль для приложений (App-Specific Password). Путь: appleid.apple.com → Безопасность → Пароли приложений → Создать.
## ⚙️ Пошаговая установка
Шаг 1: Создание сервисного аккаунта.

Шаг 2: Создание Cloud Function
1. Перейдите в Yandex Cloud Console → Cloud Functions → Создать функцию.
2. Среда выполнения: Python 3.12.
3. Точка входа: index.handler.
4. Таймаут: 30 секунд (критично для установления SSL-соединений).
5. Память: 128 МБ или 256 МБ.
6. Сеть: Оставьте пустым («Без сети»).

Шаг 3: Настройка переменных окружения
В разделе «Переменные окружения» функции добавьте:
Ключ-Значение-Примечание
1. YANDEX_EMAIL-ваш_email@yandex.ru-Без пробелов в начале/конце
2. YANDEX_PASSWORD-xxxxxxxxxxxxxxxx-Пароль приложений Яндекса
3. ICLOUD_EMAIL-ваш_apple_id@icloud.com-Без пробелов
4. ICLOUD_PASSWORD-xxxx-xxxx-xxxx-xxxx-Пароль приложений Apple (с дефисами!)

Шаг 4: Развертывание кода
Создайте два файла в редакторе функции:
1. requirements.txt
2. index.py

Шаг 5: Настройка триггера (Timer)
1. Перейдите в Cloud Functions → ваша функция → вкладка Триггеры → Создать триггер.
2. Тип триггера: Таймер.
3. Имя: daily-deadline-check.
4. Расписание (Cron): 0 0 * * * (каждый день в 00:00 по Москве) или 0 */6 * * * (каждые 6 часов).
5. Сервисный аккаунт: выберите созданный на Шаге 1 (или аккаунт по умолчанию).
6. Функция: выберите вашу функцию.

## 🔄 Как адаптировать под другие задачи
- Другая почта: Измените imap.yandex.ru на imap.gmail.com (порт 993) и обновите логику паролей.
- Другой календарь: Измените TARGET_CALENDAR_NAME и TARGET_MAILBOX_NAME.
- Другой формат писем: Отредактируйте регулярные выражения в функции parse_assignment_email (добавьте отладочный вывод в логи, чтобы увидеть сырой текст письма).
